# ТехноДом Пенза — сайт-витрина интернет-магазина

Статический многостраничный сайт бытовой техники и товаров для дома.
Собран по брифу: без серверной части, без онлайн-оплаты, заявка подтверждается менеджером.

## Как открыть

Серверная часть не нужна — сайт работает при открытии файла напрямую.

1. Откройте `index.html` двойным щелчком в браузере.
2. Навигация по страницам — обычными ссылками.
3. Каталог, корзина и формы работают на клиенте (JS + localStorage).

Если хотите локальный сервер (необязательно):

```bash
# из папки сайта
python -m http.server 8080
# затем откройте http://localhost:8080/
```

## Что менять (карта правок)

| Что нужно | Где менять |
|---|---|
| Товары, цены, наличие | `assets/js/data.js` → массив `PRODUCTS` |
| Категории и бренды | `assets/js/data.js` → `CATEGORIES`, `BRANDS` |
| Телефон, e-mail, реквизиты | `assets/js/data.js` → `SITE`, и текст в `<footer>` на страницах |
| Цвета и типографика | `assets/css/styles.css` → блок `:root` |
| Условия доставки/оплаты | `delivery.html` |
| Тексты «О компании», политики | `about.html`, `privacy.html` |
| Фото товаров | заменить `assets/img/cat-*.svg` на реальные фото (формат 4:3) |
| Домен в SEO | `sitemap.xml`, `robots.txt`, `canonical` в `<head>` |

## Состояния интерфейса (проверено)

- **Загрузка каталога** — скелетоны карточек.
- **Пустой результат** — заглушка с подсказкой и кнопкой сброса фильтров.
- **Ошибка загрузки** — блок с кнопкой «Повторить» (демо: откройте `catalog.html?simulateError=1`).
- **Корзина пуста** — отдельный экран с CTA в каталог.
- **Формы** — валидация обязательных полей, маска телефона, сообщения под полем, экран успеха.
- **Товар не найден** — открытие `product.html` без параметра `id` или с неизвестным `id`.
- **Кнопки** — обычное, наведение, нажатие, отключённое, состояние загрузки.

## Важно перед публикацией

1. Заменить демо-данные: реальные цены, наличие, фото, названия.
2. Указать реальные ИНН/ОГРНИП, адрес, телефон и e-mail.
3. Проверить текст политики конфиденциальности под свою деятельность.
4. Подключить Яндекс.Метрику и цели на отправку заявки (по брифу — на первом этапе не подключено).
5. Онлайн-оплаты нет намеренно — оплата при получении или по счёту.

## Дизайн v2 и направления

Интерфейс обновлён: тёплый ритейл — доверие и цена как главный герой.

- Шрифты: Manrope (интерфейс) + Playfair Display (заголовки), подключены через Google Fonts с системным фолбэком.
- Иконки: линейные SVG (`assets/js/icons.js`), emoji в интерфейсе не используются.
- Итог применения: единый акцент `--brand: #1d4ed8`, крупная цена, явное наличие, «панель доверия» и полоса преимуществ на главной.
- Приёмка интерфейса: `autoclaw-design-capability` в режиме Redesign (Layout Restructure + Refinement).

Три независимых направления лежат в `design/`:

| Файл | Направление | Идея |
|---|---|---|
| `V1-ТехноДом-Пенза-направление-A.html` | Тёплый ритейл | Белый фон, глубокий синий, serif-заголовки, крупная цена (применено к сайту) |
| `V1-ТехноДом-Пенза-направление-B.html` | Каталог-витрина | Серый холст, список товаров, плотная витрина, teal-акцент |
| `V1-ТехноДом-Пенза-направление-C.html` | Контрастный техно | Тёмный баннер, жёлтый акцент, моно-цифры, жёсткая сетка |

Направления отличаются концепцией и композицией, а не только цветом. Выбранное направление A уже реализовано во всём сайте.

## Технологии и ограничения

- Чистый HTML/CSS/JS, без сборки и зависимостей.
- Данные каталога — в JS-файле (а не в JSON), чтобы сайт работал по `file://` без сервера.
- Нет серверной части, оплаты и отправки писем: форма заявки в демо-режиме ничего не отправляет.
- Изображения — локальные SVG, чужие фото и логотипы не используются.
